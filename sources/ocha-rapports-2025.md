# Sources : OCHA Gaza Humanitarian Response Updates 2025

UN-OCHA publie tous les ~15 jours un *Gaza Humanitarian Response Update* qui donne l'état des opérations humanitaires multi-secteurs, dont la section WASH.

---

## Rôle dans l'enquête

**Avant la v4** : seules sources publiques pour suivre l'évolution du cluster (nombre de partenaires, volumes agrégés) → utilisées pour cadrer le Constat 3 (évolution 2022→2025).

**Limite forte** : ces rapports donnent des **agrégats**, jamais de ventilation par partenaire individuel. C'est précisément cette limite qui faisait que la v3 statuait « ranking non vérifiable » sur le slogan « #2 ».

**En v4** : le [dashboard Power BI](dashboard-powerbi-wash-cluster.md) a permis de descendre au niveau partenaire. Les rapports OCHA restent utiles pour :
- Confirmer que le dashboard reflète la réalité aggregate (les ordres de grandeur correspondent)
- Documenter le contexte d'évolution du cluster

## Croisement avec le dashboard

Le dashboard daté du 23 septembre 2025 (visible dans la pub) montre :
- 41 partenaires actifs
- 1 370 points d'eau
- 13 996 m³/jour d'eau potable
- 7 347 m³/jour d'eau domestique

→ **Cohérent** avec les rapports OCHA pour la même période. Le visuel utilisé par la pub correspond bien à un dashboard officiel et réel.

|---|---|

| Les volumes livrés sont de l'ordre de 13 000 à 22 000 m³/jour | ✅ Confirmé |
| Le tableau de bord daté du 23 septembre 2025 est cohérent avec ces chiffres | ✅ Très probable |
| Tel partenaire individuel est #1, #2, #3 par volume | ❌ Les rapports ne ventilent pas par partenaire |

---

## Mention de Human Appeal dans ces rapports

Aucun rapport OCHA consulté (recherches du 22 mai 2026) ne mentionne **nominativement Human Appeal** parmi les acteurs WASH cités. Les organisations citées nominativement dans les sections WASH sont typiquement les Area Focal Points (Oxfam, Action Against Hunger, Save the Children, Islamic Relief, WeWorld-GVC) ou les fournisseurs techniques majeurs (UNICEF, PWA, CMWU).

C'est cohérent avec [Constat 2](../constats/02-instances-coordination.md) (HA n'est pas dans les instances de coordination) et avec le fait que HA est un partenaire **modeste** en volume (Constat 4).
